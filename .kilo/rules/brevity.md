# Code Brevity

Code must be as short and concise as possible without reducing performance, readability, or correctness.

## Requirements

- Refactor, simplify, and remove all redundancy.
- Follow DRY principles: eliminate duplication across the codebase.
- Avoid unnecessary abstractions, indirection, or intermediate variables.
- Deliver the most efficient minimal implementation that still behaves identically to a full-length solution.
- Prefer straightforward logic over clever tricks.
